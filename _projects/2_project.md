While consulting with **Clause Technology** in collaboration with **NCIS**, I built an agentic system for detecting illegal fishing activity and maritime criminal behaviour from open-source reporting.

- **Automated ingestion:** web scraping of incident reports with NLP-based classification
- **Entity recognition:** BERT/NER pipelines for vessels, locations, and organizations, with LLM-assisted similarity de-duplication
- **Deployment:** dockerized architecture on MongoDB/PostgreSQL
- **Impact:** achieved a **65% reduction in manual triage time**

The project extends my earlier capstone supervision work on vessel trajectory analysis with NCIS, and demonstrates the transferability of clinical-AI methods — multi-source data engineering, class-imbalanced prediction, and human-in-the-loop triage — to security contexts.
